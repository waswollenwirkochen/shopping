# Einkauf

Einkaufslisten-App (installierbar am Handy). Listen werden verschlüsselt im privaten Repository `shopping-data` gespeichert, jede Liste mit eigenem Schlüssel.

- Antippen: erledigt (verschwindet mit Dreh-Animation)
- Gedrückt halten oder Rechtsklick: bearbeiten (Name, Eigenschaften, Kategorie)
- Shortcuts für regelmäßige Einkäufe, Vorschläge aus zuletzt verwendeten Einträgen
- Listen teilen per Link (Menü ⋯ → Teilen)
- Übertragung aus dem Wochenplan des Gerichte-Rosters
